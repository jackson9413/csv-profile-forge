csv-profile-forge

Paste a CSV. Get a column profile, prioritized fixes, a cleaning plan and a cleaned file.

100% local · no API keys GitHub

1. Paste the data

CSV, TSV, semicolon or pipe delimited. Nothing leaves this machine.

2. Read the report

Paste data on the left and press Profile dataset. You will get:

  • Column-by-column profile: type, missingness, uniqueness, top values, outliers
  • Prioritized findings with the offending row numbers and a concrete fix
  • A 5-axis quality score (completeness, consistency, validity, uniqueness, structure)
  • A cleaning plan, plus a downloadable CSV with the safe fixes already applied
